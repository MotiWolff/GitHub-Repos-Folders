# GitHub Repo Folders Privacy Policy

GitHub Repo Folders does not collect, sell, or share personal data.

## What the extension stores

- The extension stores folder names, folder collapsed/expanded state, and repository-to-folder assignments.
- This data is stored locally in the user’s browser using Chrome storage and is scoped per GitHub account.

## What the extension transmits

- The extension does not transmit stored folder data to any third-party servers.
- If the user uses the “Load all pages” feature, the extension requests additional paginated repository list pages from `github.com` to build a combined view. These requests use the user’s existing GitHub session, and the extension does not send the stored folder data with these requests beyond what the browser normally sends to GitHub for normal page loading.

## Data retention and deletion

- The user can delete extension data at any time using the “Clear data for this account” button inside the extension UI, or by removing the extension.

## Contact / Support

For support, please use the project’s support page or issue tracker.
