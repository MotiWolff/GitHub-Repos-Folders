# GitHub Repo Folders (Chrome Extension)

This Chrome extension lets you **group GitHub repositories into folders in the GitHub UI** (visual grouping only). It currently targets GitHub repository list pages (like your profile “Repositories” tab).

## What it does (MVP)

- Adds a **Folders** panel above the repo list
- Lets you **create / rename / delete** folders
- Adds a per-repo **Folder** dropdown (“Unfiled” or a folder)
- Reorders the repo list into **folder sections** (with **collapse/expand** per folder)
- Persists everything in `chrome.storage` (sync if available)

## Install (developer mode)

1. Open Chrome and go to `chrome://extensions`
2. Enable **Developer mode**
3. Click **Load unpacked**
4. Select this folder (`GitHub-Folders-Extension`)
5. If you later click **Reload** on the extension, also **refresh the GitHub page** (so the new content script is injected).
5. Go to GitHub and open a repositories list page, e.g.:
   - `https://github.com/<your-username>?tab=repositories`

## Notes

- This is **UI-only** grouping; it does not change GitHub data.
- GitHub uses dynamic navigation; the script listens for Turbo/PJAX and DOM updates.
- Icons are generated by `scripts/generate_icons.py` into `icons/`.
- Folders are stored **per GitHub account** (so different logins get different folder sets).
